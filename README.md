## Overview
**CineScope** is a modern, responsive, and API-driven web application built with **ASP.NET Core** and **Razor Pages**. It provides **real-time information** about movies, TV series, and celebrities using the **TMDB API**.  

CineScope does **not rely on a local database**, ensuring all content is always fresh and up-to-date.

The application also includes a fully functional **contact form** to collect user suggestions via **Formspree**.

---

## Features
- Explore **popular, top-rated, and upcoming movies and TV series**.
- Discover content by **genre, release year, and popularity**.
- Search across **movies, TV shows, and actors**.
- Detailed pages for movies, series, and persons including **credits, trailers, and reviews**.
- **Responsive design** for desktop, tablet, and mobile devices.
- **User-friendly contact form** for feedback and suggestions.
- Smooth **animations and modern UI design**.

## Technologies Used
- **Backend:** ASP.NET Core, C#  
- **Frontend:** Razor Pages, HTML5, CSS3, JavaScript  
- **API:** TMDB API for movies, series, and people  
- **Forms:** Formspree for contact form submission  
- **Styling:** Modern CSS with animations and hover effects  

---

## Usage
1. Navigate through movies, series, and people.  
2. Use the **search bar** to find specific content.  
3. Click **Contact Us** to send suggestions via the contact form.
